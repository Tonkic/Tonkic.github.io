## Agent skills

### Issue tracker

Issues for this repo are tracked in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. Read root `CONTEXT.md` when present, and `docs/adr/` for architectural decisions. The `docs/` directory contains documentation for implemented features, project architecture, and feature information; it is not the issue tracker or a requirements backlog. See `docs/agents/domain.md`.
