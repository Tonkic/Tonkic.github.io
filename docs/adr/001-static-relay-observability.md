# ADR 001：静态站的中转服务状态展示

## 状态

已采用。

## 背景

网站部署在 HTTPS 的 GitHub Pages，中转站当前为 HTTP，且公开接口没有开放 CORS。浏览器不能从本站可靠读取 `/api/status` 和 `/api/pricing`。将 API Key 放入前端也不可接受。

## 决策

采用两层状态机制：

1. GitHub Actions 每 15 分钟运行 `scripts/sync-relay-snapshot.mjs`，读取无需鉴权的公开接口并构建静态快照。
2. 浏览器保留实时探测逻辑；仅当中转站提供 HTTPS 且允许本站跨域读取时启用，每 60 秒探测一次。

快照只保存公开字段：服务是否可达、探测时间、系统名、版本、公开模型、供应商、价格和 endpoint 类型。任何 API Key、用户信息、额度和请求记录都不得进入仓库或前端资源。

## 结果

- 当前架构下可以提供约 15 分钟粒度的公开状态。
- 中转站升级 HTTPS/CORS 后无需重构页面即可获得分钟级实时状态。
- 部署过程会依赖公开接口，但同步失败时脚本会保留最近模型数据并标记本次探测失败。
